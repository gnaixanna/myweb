Hölder's inequality

Updated on 08/16/2026

We want to prove that

$$\sum_{k=1}^{n} \left | x_{k}y_{k}\right |\leqslant \left [ \sum_{k=1}^{n} \left | x_{k}\right | ^{p}\right ]^{1/p}\left [ \sum_{k=1}^{n} \left | y_{k}\right |^{q}\right ]^{1/q}$$

Where $$p,q$$ are real numbers and $$\frac{1}{p} + \frac{1}{q} = 1$$.

First, starting from cases with the same power. $$\sqrt[3]{\sum a_{i}^{3}}\sqrt[3]{\sum b_{i}^{3}}\sqrt[3]{\sum c_{i}^{3}} \geq \sum a_{i}b_{i}c_{i}$$

Say $$A = \sqrt[3]{\sum a_{i}^{3}}$$, and the same for B and C. Say $$x_{i} = \frac{a_{i}}{A}$$ and the same for $$y_{i}$$ and $$z_{i}$$.

Now this is good because $$x_{i}^3 = 1$$.

Now we want to prove that $$x_{i}y_{i}z_{i} \leq 1$$.

For each $i$, we have $\frac{x_{i}^3+y_{i}^3+z_{i}^3}{3} \geq \sqrt[3]{x_{i}^3y_{i}^3z_{i}^3} = x_{i}y_{i}z_{i}$
